# ASA Black Box 1.5.0: проверка на роботе

Время: около 1 часа. Нужны: робот с Control Hub (лучше и с Expansion Hub), Driver Hub, телефон или ноутбук,
заряженная батарея, подставка, чтобы колёса висели в воздухе.

Надписи в плане на английском: в INIT программы «ASA Black Box» включите английский кнопкой **X**
(или сравнивайте по смыслу на своём языке).

Как записывать результат: у каждого шага отметьте ✅ (как написано), ⚠️ (иначе, но работает) или ❌ (не работает).
На каждый ⚠️ и ❌ сделайте фото экрана Driver Hub и/или страницы.

## 1. Основные 7 шагов (из README)

| # | Что сделать | Что должно быть |
|---|---|---|
| 1 | Выбрать **ASA Black Box**, INIT (без START) | 🟢 «Every match is recorded (hooked in at power-on)» и строка «RESULTS: … :8099» |
| 2 | Телефон в Wi-Fi робота, открыть адрес из шага 1 | страница с логотипом ASA, зелёная точка «robot online» вверху |
| 3 | В ASA Black Box: **RB** до «Recording test», START. Робот стоит, около 16 с | три зелёные строки: цикл с записью почти такой же, как без неё; замеров около ожидаемого; энкодеры читаются на каждом моторе |
| 4 | Робот на подставке. ASA Black Box → «Health check», START, **Y** | для каждого мотора зелёное «OK … encoder counts up». Красное или жёлтое — настоящая находка: провод, порт или направление |
| 5 | Запустить **свой** TeleOp: INIT, START, минуту ездить, STOP | во время езды на странице живые графики (вкладка «Live» / «Сейчас»); после STOP открывается запись с именем вашего TeleOp |
| 6 | Снова INIT ASA Black Box | «Newest recording: <ваш TeleOp>, время» |
| 7 | Там **Y** → «Automatic recording is off», запустить свой TeleOp | новой записи нет. Потом включить обратно (**Y**) |

**Обязательно сфотографируйте шаг 3**: экран с тремя строками нужен нам в любом случае.

## 2. Проверка исправленных ошибок

Эти ошибки нашла проверка кода. Исправления прошли тесты на компьютере, но на настоящем роботе их ещё никто не видел.

| # | Что сделать | Что должно быть |

## 3. «Удалить ASA» (делать в конце, на копии или когда ASA больше не нужна)

| # | Что сделать | Что должно быть |
|---|---|---|
| 3.1 | Если ваш код использует Black Box: ASA Black Box → **RB** до «Remove ASA», START | красное «Your code uses Black Box, so nothing is removed» и список ваших файлов. Ничего не удалено |
| 3.2 | Если лежат старые файлы ASA 1.4 без метки | жёлтое «These files have ASA's names but not its mark», список. Ничего не удалено |
| 3.3 | Без этого: зажать **A + B** на 3 с | полоска заполняется; отпустить раньше — отмена |
| 3.4 | Держать до конца, потом STOP → OnBot Java → Build | «ASA removed». В OnBot Java нет ни одного файла ASA, **все ваши файлы на месте**, Build проходит |
| 3.5 | Если стоит и ASA SysId | SysId работает, константы (`sysid/*.ff`) на месте |
