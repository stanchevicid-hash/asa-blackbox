# OnBot Java: the 17 files

No Android Studio? Upload **all 17 `.java` files of this folder** into your usual `teamcode` folder in OnBot Java
(`http://192.168.43.1:8080` on the robot Wi-Fi), without subfolders, and press Build (again if the first build says
"bad source file"). Then Restart Robot once. Generated from `src/` by `onbot.py`: change `src/`, not these files.
